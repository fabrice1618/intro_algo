## Exercice 2 - Reconnaître les structures ★

Pour chaque situation, indiquer la structure (séquentielle, conditionnelle, itérative) qui convient :

1. Calculer le prix TTC d'un article à partir de son prix HT
2. Appliquer une remise de 10 % seulement si le client a une carte de fidélité
3. Additionner les prix de tous les articles d'un panier
4. Redemander un code PIN tant qu'il est faux

<details>
<summary>Solution</summary>

1. séquentielle, 2. conditionnelle, 3. itérative, 4. itérative (avec une condition d'arrêt)
</details>
